PORTAL KEPERAWATAN v2.1 — PAKET LENGKAP

Isi paket:
- Kode website lengkap untuk GitHub Pages/PWA.
- 7 modul utama dengan materi HTML, kuis, referensi, dan poster visual.
- Poster baru telah dikonversi ke WebP dan dilengkapi thumbnail ringan.
- Poster prosedural lama yang masih relevan: kebersihan tangan, APAR, dan spill kit.
- Poster BHD lama berlabel AHA 2026 tidak dimasukkan ke modul agar tidak membingungkan. Materi BHD tetap tersedia sebagai HTML AHA 2025 sampai poster pengganti selesai.

CARA MEMASANG
1. Ekstrak ZIP.
2. Upload seluruh ISI folder ini ke root repository GitHub.
3. Pastikan folder assets dan content ikut terunggah.
4. Commit, tunggu deployment GitHub Pages selesai.
5. Buka portal dan tekan Ctrl+F5.

CATATAN
Portal ini merupakan inisiatif pembelajaran mandiri, bukan situs resmi rumah sakit. Detail operasional lokal seperti nomor Code Blue dan alur internal mengikuti kebijakan fasilitas.
