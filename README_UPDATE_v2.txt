CARA UPDATE GITHUB PAGES

Versi ini mengubah banyak file. Cara paling aman:
1. Ekstrak ZIP.
2. Di repository GitHub, unggah seluruh isi folder Portal_Keperawatan_GitHub_Pages_v2_0 ke root repository.
3. Pastikan folder assets dan content ikut terunggah.
4. Commit perubahan.
5. Tunggu GitHub Pages selesai deploy.
6. Buka portal lalu Ctrl+F5. Pada PWA mobile yang masih lama, tutup dan buka ulang; bila perlu hapus data situs/instal ulang PWA.

Catatan: portal ini mandiri, bukan situs resmi rumah sakit. Nomor Code Blue, chart lokal, dan detail kebijakan internal tetap mengikuti fasilitas.
