PORTAL KEPERAWATAN v3.0 FINAL
================================

PERUBAHAN UTAMA
- Navigasi dua tingkat: Beranda → Kelompok standar → Submateri → Pembelajaran.
- Kelompok: SKP, PP, PAP, PPI, PKPO, PMKP, HPK, KE, dan MFK.
- SKP kembali menjadi fondasi khusus dengan ringkasan enam SKP dan enam materi terpisah.
- PP diperkuat: pengkajian awal, skrining, pengkajian ulang, CPPT, dan pengkajian khusus.
- PAP memiliki submateri mandiri: asuhan terintegrasi, pasien risiko tinggi, EWS,
  BHD, Code Blue, nyeri, nutrisi, dan akhir hayat.
- PMKP dipisahkan menjadi:
  1) Mutu, Indikator, dan Perbaikan Berkelanjutan.
  2) Keselamatan Pasien, IKP, dan Manajemen Risiko.
- Tiga poster BHD baru dimasukkan dengan urutan tetap:
  1) Respons awal, aktivasi bantuan, dan AED.
  2) Kompresi dada berkualitas tinggi.
  3) Jalan napas, ventilasi, dan tersedak.
- Poster dikonversi ke WebP dan disertai thumbnail.
- Cache PWA dinaikkan ke portal-keperawatan-v3.0.0.

CARA MEMASANG
1. Ekstrak ZIP.
2. Unggah seluruh isi folder ke root repository GitHub.
3. Pastikan folder assets/ dan content/ ikut terunggah.
4. Tunggu GitHub Pages selesai deployment.
5. Buka portal dan tekan Ctrl+F5.
6. Bila PWA HP masih menampilkan versi lama, hapus data situs atau instal ulang PWA.
